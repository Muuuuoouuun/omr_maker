# 프리미엄 서비스 심화 기획: 낮은 난이도, 높은 가치

작성일: 2026-08-28

## 결론

이 서비스의 프리미엄 가치는 분석 화면의 깊이가 아니라 **시험 후 남는 일을 자동으로 정리해
주는 것**에서 나온다.

- 강사: 모든 학생을 설정하지 않고 제안된 과제에서 예외만 확인한다.
- 학생: 분석을 해석하지 않고 `오늘 할 보충` 하나만 시작한다.
- 학부모: 점수표 대신 학원이 어떤 조치를 했고 무엇이 회복됐는지 본다.

제품의 중심 문장은 `AI 분석`이 아니라 **시험이 끝나면 보충까지 정리됩니다**로 잡는다.

## 제품 원칙

### 1. 설정 전에 첫 가치를 보여준다

시험 제출이 끝나면 별도 설정 없이 `보충 필요 학생`, `추천 문항`, `예상 소요시간`을 먼저
계산한다. 과목·반·마감 정책은 직전 시험 값을 재사용한다.

### 2. 자동 결정이 아니라 자동 제안이다

학생에게 영향을 주는 배정과 외부 메시지는 강사가 승인한다. 시스템은 범위, 이유, 제외할
학생만 보여준다. `전원 자동 발송`은 기본값으로 두지 않는다.

### 3. 차트보다 다음 행동을 먼저 보여준다

첫 화면은 `누가`, `무엇을`, `언제까지` 해야 하는지 답해야 한다. 상세 오답률과 행동 신호는
두 번째 단계에서 펼친다.

### 4. 학생에게 선택지를 넘기지 않는다

학생은 `오답만/유형별/전체`를 고르지 않는다. 강사가 승인한 하나의 과제가 `오늘 할 보충`으로
나오고, 학생은 시작 또는 이어하기만 한다.

### 5. AI보다 근거를 보여준다

추천 옆에 `5, 8번 오답`, `같은 개념 2문항`, `최근 3회 반복`처럼 한 줄 근거를 붙인다.
근거가 약하면 `단일 오답` 또는 `참고 경향`이라고 표시한다.

## 가장 먼저 만들 서비스 5개

| 서비스 순간 | 사용자 행동 | 체감 가치 | 구현 난도 | 기존 자산 |
| --- | ---: | --- | --- | --- |
| 오늘의 오답 10문항 | 강사 승인 1회 | 매우 높음 | 낮음 | 오답 ID, 재시험 링크, 회복률 |
| 예외만 확인 | 문제 있는 행만 검토 | 매우 높음 | 낮음 | 정답/태그/명단 준비도 |
| 학생 오늘 할 보충 | 시작 1회 | 높음 | 낮음 | 학생 과제, 복습 이력 |
| 회복 신호등 | 행동 없음 | 높음 | 낮음 | 회복/미회복/다시 틀림 |
| 학부모 상담 1페이지 | 인쇄 1회 | 높음 | 낮음 | 리포트, 반복 약점, 회복률 |

이 다섯 가지는 새 AI 모델이나 문항은행 없이 현재 데이터를 재조합해 만들 수 있다.

## 핵심 서비스 흐름

### A. 시험 종료 직후: 강사 1분 승인

상단에는 한 문장만 보여준다.

> 24명 중 17명에게 보충이 필요합니다. 학생별 최대 10문항, 예상 8분, 48시간 마감으로
> 준비했습니다.

기본 화면:

- 17명 선택, 7명 제외
- 학생별 3~10문항, 10문항 초과 시 두 과제로 자동 분할
- 추천 이유는 한 줄만 표시
- `검토 후 배정`을 기본 버튼으로 제공
- `바로 배정`은 이전에 같은 정책을 사용한 반에서만 노출

강사가 봐야 하는 예외:

- 정답 또는 채점 결과 누락
- 유형 태그가 없어 유형별 과제를 만들 수 없음
- 명단과 연결되지 않은 학생
- 10문항을 초과한 학생
- 이미 같은 범위의 재시험을 완료한 학생

### B. 학생: 오늘 할 보충

학생 대시보드 첫 카드:

- `오늘 할 보충 7문항`
- `약 8분 · 내일 수업 전까지`
- `시작하기` 또는 `이어하기`
- 완료 후 `7문항 중 5문항 회복` 표시

학생에게 오답률, 신뢰도, 분석 축을 먼저 보여주지 않는다. 상세 복습 화면에서만 근거와 해설을
펼친다.

재도전 기본값:

- 최대 2회
- 제출 전에는 정답을 공개하지 않음
- 2회 후 미회복 문항은 다시 반복시키지 않고 `선생님과 확인`으로 전환
- 정답이지만 오래 걸린 문항은 자동 과제에 넣지 않고 강사 참고 신호로만 둠

### C. 강사: 회복 신호등

반 단위 상태를 네 개만 사용한다.

- 초록 `회복`: 원시험 오답을 맞힘
- 파랑 `진행 중`: 시작했지만 미제출
- 회색 `미시작`: 배정 후 시작하지 않음
- 빨강 `확인 필요`: 2회 후에도 미회복 또는 다시 틀림

첫 화면에서는 학생 이름과 상태만 보고, 문항 근거는 눌러서 확인한다. `확인 필요` 학생만 다음
수업 액션 큐로 올린다.

### D. 학부모 상담: 조치가 보이는 1페이지

리포트 순서는 다음과 같다.

1. 이번 시험 결과
2. 학원이 배정한 보충
3. 학생의 완료 여부와 회복 문항
4. 반복되는 약점 최대 3개
5. 다음 수업에서 할 조치

`집중력이 부족합니다` 같은 해석 대신 `미응답 3문항`, `재시험 2회 후 1문항 미회복`처럼
관찰 사실을 쓴다. 초기에는 교사가 인쇄/PDF로 전달하고, 보호자 전용 링크는 권한·보관 정책이
갖춰진 뒤 제공한다.

## 기본 운영 정책

| 항목 | 기본값 | 이유 |
| --- | --- | --- |
| 배정 승인 | 강사 승인 필수 | 잘못된 자동 배정 방지 |
| 자동 후보 | 오답·미응답 2문항 이상 | 한 문제 실수를 과제화하지 않음 |
| 과제 길이 | 최대 10문항 | 5~12분 안에 끝나는 크기 |
| 마감 | 48시간 또는 다음 수업 전 | 학원 시간표와 맞추기 쉬움 |
| 재도전 | 최대 2회 | 무한 반복 피로 방지 |
| 정답 공개 | 제출 후 | 답 외우기 방지 |
| 느린 정답 | 자동 배정 제외 | 참고 신호를 오답으로 취급하지 않음 |
| 미회복 | 교사 확인으로 전환 | 설명 없는 반복 중단 |

반별로 `숙제형`, `수업 전 보충형`, `주간 클리닉형` 템플릿을 저장할 수 있지만 첫 사용 전에
템플릿 설정을 요구하지 않는다.

## 오늘의 우선 조치 화면

강사 대시보드는 분석 메뉴보다 운영 큐를 먼저 보여준다.

1. `승인 대기 2건` — 방금 끝난 시험의 보충 과제
2. `오늘 마감 7명` — 진행 중 또는 미시작
3. `확인 필요 3명` — 2회 후에도 미회복
4. `상담 준비 1건` — 주간/월간 리포트

각 항목은 하나의 대표 버튼만 갖는다. 필터, 차트, 세부 설정은 상세 화면으로 보낸다.

## 알림 전략

### 카카오 연동 전

- 강사가 승인한 학생만 발송 후보로 만든다.
- 메시지 문구와 링크를 한 번에 복사한다.
- QR을 수업 화면이나 인쇄물에 제공한다.
- `발송됨` 대신 `복사됨`, `대기 기록`처럼 실제 상태만 표시한다.

### 카카오 연동 후

- 발송 성공, 실패, 수신 불가를 분리한다.
- 미시작 학생에게만 1회 재알림한다.
- 보호자 메시지는 별도 동의와 수신 대상을 확인한다.
- 학습 행동 로그나 상세 성적을 메시지 본문에 직접 넣지 않는다.

## 과금 경계

프리미엄은 학생의 결과를 가리는 방식보다 **강사의 반복 업무를 줄이는 기능**에 과금한다.

### Free

- 개별 시험 점수와 오답 확인
- 학생이 이미 배정받은 과제의 완료 접근 보장
- 강사가 학생별 재시험 링크를 수동 생성

### Pro

- 반 단위 자동 후보와 일괄 승인
- 마감·미완료·확인 필요 큐
- 유형별 오답 과제와 회복 신호등
- 상담 1페이지와 반별 운영 템플릿

### Academy

- 여러 강사의 승인/수정 권한
- 학원 공통 운영 정책과 감사 이력
- 지점·반·교사 단위 회복 현황
- 보관 기간, 보호자 전달 정책

플랜이 내려가도 이미 배정된 학생 과제는 마감일까지 열어 둔다. 교사 플랜 변경 때문에 학생
학습이 중간에 막히면 서비스 신뢰가 크게 떨어진다.

## 만들지 말아야 할 것

- 첫 사용 전에 복잡한 분석 기준 설정
- 근거 없는 AI 오답 원인 단정
- 학생에게 여러 재시험 모드를 선택하게 하는 화면
- 매 제출마다 보호자에게 자동 발송
- 미완료 학생을 공개 순위로 노출
- 한 문제 오답을 `취약 개념`으로 확정
- 새 문항은행 전의 `AI 유사문항 무제한` 약속

- 마감과 최대 재도전
- 미시작·미회복 큐
- 반별 정책 템플릿

### 3차: 실제 채널과 조직 운영

- 카카오 실제 발송과 실패 처리
- 보호자 전달 동의
- 다중 강사 권한과 감사 로그
- 조직 단위 운영 정책

## 성공 기준

- 신규 강사가 첫 보충 과제를 5분 안에 배정
- 반복 사용 강사는 1분 안에 승인
- 학생 과제 시작까지 평균 탭 2회 이하
- 학생별 과제 중앙값 10문항 이하
- 강사 수동 제외/수정률 15% 이하
- 보충 과제 완료율 80% 이상
- 오답 회복률 60% 이상

가장 중요한 검증 질문은 `분석이 정확해 보입니까?`가 아니라 **이 기능 때문에 시험 후 처리
시간이 실제로 줄었습니까?**다.
