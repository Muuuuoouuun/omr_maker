# 프리미엄 오답 회복 서비스

작성일: 2026-08-28

## 한 줄 정의

시험을 채점하는 도구에서 끝나지 않고, 강사가 3분 안에 보충 대상을 확정하고 학생이
오답을 다시 풀며 학원은 회복 결과를 상담 자료로 남기는 서비스다.

핵심 지표는 조회수나 AI 분석 수가 아니라 **오답 회복률**이다.

사용자 난이도를 낮추면서 서비스 가치를 높이는 상세 경험과 기본 운영 정책은
[`premium-service-experience.md`](./premium-service-experience.md)를 기준으로 한다.

## 시장 현실

2025년 초중고 사교육 참여율은 75.7%, 참여 학생의 월평균 사교육비는 60만 4천 원,
주당 참여시간은 7.1시간이었다. 전체 학생 수와 참여율은 줄었지만 참여 학생 1인당 지출은
늘었다. 학원은 기능 개수보다 제한된 시간 안에 학습 조치를 끝내고, 학부모에게 그 결과를
설명할 수 있는 도구에 비용을 지불할 가능성이 높다.

근거: [2025년 초중고 사교육비 조사 결과, 국가데이터처](https://www.kostat.go.kr/board.es?act=view&bid=245&list_no=443953&mid=a10301010000)

## 기능 평가

| 기능 | 학습 효과 | 강사 시간 절감 | 현재 데이터 신뢰도 | 구현/운영 난도 | 우선순위 |
| --- | ---: | ---: | ---: | ---: | --- |
| 오답 복습 목록 | 5 | 4 | 5 | 2 | P0 |
| 오답 유형 정리 | 4 | 5 | 3 | 3 | P0, 태그 준비도 전제 |
| 오답 다시 풀기 | 5 | 5 | 5 | 2 | P0 |
| 유형별 오답 다시 풀기 | 4 | 4 | 3 | 3 | P1, 새 문제 아님 |
| 새 유사문항 추천 | 4 | 3 | 2 | 5 | P2, 문항은행 이후 |
| 누적 심화 분석 | 4 | 4 | 3 | 4 | P1, 이력 기준 충족 시 |

### 현재 기능을 부르는 정확한 이름

- 문항 이미지, 학생 답, 정답, 해설이 한 장에 정리되지 않으면 `자동 오답노트`보다
  `오답 복습 목록`이라고 부른다.
- 같은 시험의 틀린 문항을 개념 태그로 묶은 것은 `유형별 오답 다시 풀기`다.
- 원문항과 다른 문제를 제공할 때만 `새 유사문항`이라고 부른다.
- 필기 흔적과 화면 이탈은 참고 신호다. 이해 부족이나 부정행위로 단정하지 않는다.

## 한국 학원 운영 흐름

1. 시험 종료와 동시에 자동 채점한다.
2. 강사는 `정답 누락`, `유형 태그 부족`, `학생 명단 미연결` 경고만 먼저 확인한다.
3. 시스템은 `즉시 재시험`, `수업 중 해설`, `개별 확인` 후보를 나눈다.
4. 강사가 후보를 승인하고 마감일을 정한다. 자동 발송보다 강사 승인이 우선이다.
5. 학생은 별도 앱 설치 없이 기존 학생 링크/PWA에서 오답만 다시 푼다.
6. 미시작·미완료 학생은 카카오 발송 후보 큐에 들어간다. 실제 연동 전에는 발송된 것처럼
   표시하지 않는다.
7. 재시험 후 `회복`, `미회복`, `다시 틀림`을 보여주고 다음 보충 대상을 갱신한다.
8. 학부모 상담에는 점수보다 `과제 수행`, `회복 문항`, `반복 약점`, `교사 조치`를 한 장으로
   제공한다.

학원 현장에서는 학생이 스스로 분석 화면을 찾아보는 흐름보다 강사가 일괄 배정하고 카카오나
수업 시간에 회수하는 흐름이 현실적이다. 모바일 학생 화면, 데스크톱 강사 일괄 처리, 인쇄/PDF
상담 자료의 세 표면을 한 서비스로 본다.

## 네 가지 프리미엄 기능 정의

### 1. 오답 복습 목록

학생에게 문항 번호, 학생 답, 정답, 미응답, 교사 코멘트와 원본 문제 위치를 제공한다.
강사는 반 전체의 오답률 상위 문항과 정답 누락을 먼저 본다.

완료 기준:

- 정답이 없는 문항은 오답으로 확정하지 않고 `미채점`으로 표시한다.
- 원본 PDF와 문항 영역 좌표가 있으면 해당 위치로 이동한다.
- 문항 이미지가 없으면 인쇄 가능한 오답노트가 완성된 것처럼 홍보하지 않는다.

### 2. 오답 유형 정리

개념, 단원, 스킬, 오답 원인 태그로 오답을 묶고 `틀린 수/대상 수`와 근거 문항을 함께
보여준다. AI가 추정한 유형과 강사가 확정한 유형은 구분해 저장해야 한다.

노출 기준:

- 한 유형에 태그된 문항이 2개 미만이면 `경향` 대신 `단일 오답`으로 표시한다.
- 누적 반복 약점은 원시험 3회 이상, 해당 유형 결과 6개 이상일 때 확정적으로 노출한다.
- 반 패턴은 응시 학생 5명 미만이면 참고값으로만 보여준다.
- 학생 명단이 연결되지 않으면 동명이인 누적 분석을 중단한다.

### 3. 오답 다시 풀기

`오답만`, `유형별 오답`, `교사 선택` 세 가지 과제를 제공한다. 재시험 점수만 보여주지 않고
원시험에서 틀렸던 문항 중 몇 개를 회복했는지 계산한다.

운영 상태는 `후보 → 승인 → 배정 → 시작 → 제출 → 회복/미회복`으로 통일한다. 강사는 반 단위
일괄 배정, 학생별 제외, 마감일, 재도전 횟수를 조정할 수 있어야 한다.

### 4. 새 유사문항과 심화 분석

새 유사문항은 현재 시험 문항을 다시 보여주는 기능과 분리한다. 다음 조건을 모두 만족해야
출시한다.

- 학원 또는 서비스가 재사용할 권리를 가진 문항은행
- canonical question ID, 과목, 단원, 개념, 스킬, 난도, 출처, 정답
- 원문항과 다른 대체 문항 최소 3개
- 같은 지문/작품을 재사용할 때의 저작권 및 학원 간 데이터 분리
- 추천 이유와 제외 이유를 강사가 확인할 수 있는 화면

심화 분석은 점수 상승만으로 효과를 주장하지 않는다. 시험 난도가 달라질 수 있으므로
`오답 회복률`, `같은 유형 재발률`, `배정 후 완료율`, `최근 3회 원시험 추이`를 함께 본다.

## 상품 구성

### Free

- 점수, 정오답, 미응답, 기본 문항 통계
- 오답 복습 목록 미리보기
- 학생 30명/월 시험 5개 한도 유지

핵심 채점 결과까지 막으면 강사가 분석 품질을 확인하기 어렵다. 무료 플랜은 신뢰를 만드는
용도로 둔다.

### Pro

- 유형별 오답 정리와 누적 약점
- 오답/유형별 재시험 링크와 회복 분석
- 필기 보관, 교사 피드백, 상담용 인쇄/PDF
- 카카오 발송 후보 검토 큐

현재 월 19,000원은 베타 도입 가격으로는 가능하다. 실제 카카오 발송, 일괄 배정, 학부모
리포트까지 안정화되면 교사 1인 기준 39,000~59,000원 구간을 검증한다. 가격 인상은 기능 수가
아니라 월 절감 시간과 재시험 완료율로 검증한다.

### Academy

- Pro 기능과 학원 단위 계약
- 다중 교사, 관리자/강사/조교 권한, 반 이동, 감사 로그, 보관 정책
- 학원 로고 상담 리포트와 조직 단위 회복 현황

현재 다중 교사와 권한 관리가 준비 중이므로 `Academy 완성형`으로 판매하지 않는다. 먼저 1개
학원, 2~5명 강사 파일럿으로 운영 충돌과 권한 요구를 수집한다.

## 운영 지표

| 구간 | 지표 | 초기 목표 |
| --- | --- | ---: |
| 강사 | 시험 종료 후 첫 과제 승인까지 걸린 시간 | 중앙값 3분 이하 |
| 학생 | 배정 24시간 내 시작률 | 70% 이상 |
| 학생 | 재시험 완료율 | 80% 이상 |
| 학습 | 오답 회복률 | 60% 이상 |
| 학습 | 다음 원시험의 같은 유형 재발률 | 30% 이하 |
| 운영 | 강사 수동 수정률 | 10% 이하 |
| 신뢰 | 유형 태그 준비도 | 90% 이상 |

`점수 상승`은 보조 지표다. 시험 난도 차이를 통제하지 못하면 서비스 효과 지표로 단독 사용하지
않는다.

## 출시 순서

1. P0: 오답 복습 목록, 오답만 다시 풀기, 회복률, 데이터 준비도 경고
2. P1: 강사 승인/일괄 배정, 유형별 오답, 마감/미완료 큐, 상담 리포트
3. P1.5: 실제 카카오 발송과 수신/실패 상태, 학부모용 요약
4. P2: 권리 확인 문항은행, 새 유사문항 추천, 난도 조절
5. P3: 학원 조직 권한, 여러 강사 운영, 장기 코호트 분석

## 개인정보와 콘텐츠 원칙

- 만 14세 미만 학생 계정과 학부모 메시지는 법정대리인 동의 및 권리 행사를 제품 흐름에
  포함한다. 동의가 필요한 개인정보 처리에서는 법정대리인의 동의와 동의 확인이 필요하다.
- 이름, 연락처, 필기, 성적, 행동 로그는 목적별로 최소 수집하고 보관 기간과 삭제 경로를 둔다.
- 화면 이탈, 풀이 시간, 답 변경은 학습 참고 신호로만 사용한다.
- 학원이 업로드한 시험지는 조직 비공개 자산으로 취급한다. 별도 권리 확인 없이 다른 학원의
  유사문항 풀에 섞지 않는다.
