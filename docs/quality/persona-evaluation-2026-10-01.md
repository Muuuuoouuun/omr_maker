# OMR Maker 페르소나 평가 종합 (2026-10-01, 브랜치 09_win1 @ 57577e1)

평가 방식: 서브에이전트 5개가 페르소나 13명을 나눠 맡았다. 로컬 dev 서버를 Playwright로 직접 조작하고 코드를 함께 읽었다.
- 초보 학생 3명 (Sonnet)
- 초보 교사 2명 + 원장 1명 (Sonnet)
- 일주일 사용 학생 3명 (Sonnet)
- 일주일 사용 교사 1명 + 원장 1명 (Opus)
- 고수·하드 사용자 교사 1명 + 원장 1명 (Opus)

환경 한계: 로컬 dev는 Supabase 없이 `provisioned_only` 모드라 README의 `admin/admin123` 로그인이 되지 않았다. 그래서 교사 쪽 실데이터 흐름(배포 → 응시 → 채점 → 실시간)은 데모 계정(합성 데이터)과 코드로 평가했다. 학생 쪽은 시험을 직접 심어서 실제 UI로 풀었다.

"교실 한 곳·소규모"에서는 핵심 기능이 좋다. 하지만 첫 진입, 폰 화면, 규모, 조직 운영에서 점수가 급격히 떨어진다.

## 장점
1. 분석이 깊고 "다음 수업에서 뭘 할지" 중심이다. 취약 문항, 최다 오답 선지, 변별도, 선지별 분포, 풀이시간, 반 × 지역 매트릭스, 보강 세트·재시험 연결까지 있다. 모든 그룹이 1순위 강점으로 꼽았다.
2. 출제 속도가 빠르다. "빠른 정답 입력"(`31252…`)으로 20~50문항이 즉시 반영되고, 배포 체크 요약이 있고, 여러 반에 한 번에 배포할 수 있다.
3. 풀이·제출이 탄탄하다. 44px 버블, 진행도, 3초 자동저장이 있고 새로고침 후 답안과 시간이 복원된다. 빈 문항 확인, 중복 제출 방지, 타이머 5분·1분 단계 경고, 시간 종료 자동 제출도 된다.
4. 복습 UI가 잘 짜여 있다. 정답/오답 격자, "다음 오답", 오답만 재시험, 개념별 유형 큐("그래프 해석 3,6,9번 · 오답 5/5")가 있다.
5. 실시간 감독이 쓸 만하다. +5분 연장, 종료 처리, 미응시 확인, 문항별 정답률이 iPad에서도 깨지지 않는다.
6. 상태 표기가 정직하다. "준비 중", "실결제 미연동", dry_run을 그대로 보여 주고, 서버 실패 시 빈 대시보드로 위장하지 않는다.
7. 백엔드 무결성이 강하다. 서명 세션, RLS, CAS·exactly-once 제출, 불변 채점 증거가 있다. CSV 명단 엔진도 dry-run, CP949, 동명이인 처리를 지원한다.
8. 원클릭 데모 계정으로 가입 없이 Academy 분석 화면을 체험할 수 있다.

## 단점
1. 폰에서 문제지가 안 보인다. 320~393px 폭에서 PDF 영역 높이가 0px이고 도구줄이 그 자리를 다 차지한다.
2. 브라우저 호환성 때문에 크래시가 난다. pdfjs 최신 빌드는 `Map.getOrInsertComputed`를 쓰는데 이를 지원하지 않는 브라우저에서는 시험 풀이와 PDF 업로드 화면이 통째로 죽는다.
3. 첫 진입 마찰이 크다.
   - 교사: 자체 가입이 없고 "운영자" 연락처도 없다. 로그인 오류 문구에 `TEACHER_ACCOUNTS` 같은 환경변수가 노출된다.
   - 학생: 로그인이 3단계 오류를 거쳐야 끝난다. "시험 입장 확인" 팝업이 두 번 뜨고, ×를 누르면 홈으로 튕긴다. 세션이 만료되면 "홈으로 이동" 버튼 하나만 있는 막다른 화면이 나온다.
4. 규모 상한이 요금제 문구와 모순된다. 조직 단위 상한은 학생 100명, 동시 응시 100명, 시험 250개, 응시 2,000건이다. 응시가 100건을 넘으면 문항 분석이 꺼진다. 그런데 요금제는 Pro "300명", Academy "무제한"을 내세운다. 상한을 넘으면 일부만 보여 주는 게 아니라 화면 전체가 실패한다.
5. 채점 표현력이 부족하다. 주관식·복수정답이 없고, 문항은 최대 50개다. 정답을 고쳐도 재채점이 안 되고 경고도 없어, 기존 제출과 이후 제출의 채점 기준이 섞인다.
6. 조직 기능이 없다. 강사 초대, 역할 관리, 조직 대시보드, 감사 로그가 모두 "준비 중"이고 계정 하나가 조직 하나다. 조교도 시험을 삭제할 수 있다.
7. 데이터를 밖으로 꺼내기 어렵다. 서버 모드 CSV에는 이름 대신 해시가 들어가고 헤더는 영문, 시각은 UTC다. 학생 × 문항 응답 행렬, XLSX, 시험 복제가 없다.
8. 명단 CSV가 한국 학원 실정과 맞지 않는다. 헤더가 영문 `name,email,group`이어야 하고 이메일이 필수다. 학부모 연락처 열은 무시된다.
9. 알림이 사실상 비어 있다. "미응시자 전체 알람 발송" 버튼은 토스트만 띄운다. 알림 진입점이 4곳으로 흩어져 있고, 학생용 알림이나 마감 신호도 없다.
10. 운영자·개발자 용어가 교사·학생 화면에 나온다. 예: "서버 연결과 보강 관리 설정을 확인해주세요", "AI(Gemini)", "API 키".

### P1
- 학생 로그인: 3단계 오류 유도를 없애고 세 칸을 처음부터 보여 준다. 로그인된 학생에게는 "시험 입장 확인" 팝업을 생략한다(재시험은 이미 생략 중이다, `solve/[id]/page.tsx:2519`). 팝업의 ×는 홈 대신 이전 화면으로 보낸다. 게스트 기본명 "Guest Student"는 한글로 바꾼다.
- 로컬 모드에서 이름 오타("학생1")가 조용히 새 학생과 새 코드를 만든다. 시작 코드 오류 시 남은 횟수와 복구 안내가 없다.
- 폰·태블릿 세로에서 "저장됨" 표시가 CSS로 숨겨진다(`globals.css:9179`, `:9486`). 풀이 화면에 오프라인 배너가 없고, 결과 화면으로 이동하다 실패하면 크롬 공룡 오류 페이지가 뜬다.
- 태블릿 가로 초기 화면: 오른쪽 절반이 비어 있고 PDF 왼쪽이 잘리며 툴바도 잘린다.
- 이력 화면 "최근 흐름"의 방향이 반대다(`history/page.tsx:167-170`). 이력 화면에서 학습 홈으로 가는 링크가 없다.
- 재시험 결과의 "회복 성공! 🚀 0% → 100%"는 방금 본 정답을 입력한 것도 성공으로 표시한다. 문서의 원칙과 반대다.
- 문항 수가 50개를 넘으면 오류 없이 20으로 돌아간다. 빠른 정답 입력에서 `-`(빈 문항)를 지워 뒤 정답이 한 칸씩 밀린다.
- 시험 복제가 없다. DB에는 clone RPC가 있는데 UI가 없다. 충돌 토스트는 존재하지 않는 "복제본으로 저장"을 안내한다(`create/page.tsx:2506`).
- 서버 CSV에 이름이 없고 해시만 들어간다. 학생 × 문항 응답 행렬을 한 번에 내보낼 수 없다.
- 명단 CSV: 한글 헤더 별칭, 이메일 선택화, 앱 안 양식 다운로드, 학부모 연락처 열을 지원해야 한다.
- 가짜 "발송" 버튼을 실제 발송으로 연결하거나 문구를 바꾸고, 흩어진 알림 진입점 4곳을 통합한다.
- 강사 초대·역할 UI가 필요하다. 조교 쓰기 권한을 제한한다(`teacherSession.ts:20`).
- 교사 로그인 rate limit이 서비스 전체 공유 버킷(10분에 500회)이라 로그인 DoS 위험이 있다(`teacherLoginRateLimit.ts:7`).
- 새 시험 탭 두 개가 초안 슬롯 하나를 공유해 서로 덮어쓴다.
- AI 정답 인식: 문제지를 답지로 올려도 "신뢰도 95%"가 나온다. Gemini·API 키 용어가 노출된다.
- 학부모 연락처가 평문으로 노출되고, 개인정보 처리방침·동의·파기 흐름이 없다.
- README의 로컬 `admin/admin123` 안내와 실제 동작(`provisioned_only`)이 다르다.

### P2
- 데모 데이터가 화면마다 다르다(84명 / 24명 / 영문 35문항). 1280px에서 데모 대시보드 로고와 표가 잘린다. KPI 카운트업 중간값이 노출된다.
- 분류 체계가 섞여 있다(수학 시험에 "장르별"). 라벨 기본값이 영어 과목용이다. "기대 103%" 라벨이 모호하다.
- 보강·알림이 사이드바에 없고 계정 메뉴 안에만 있다. 화면마다 내비게이션이 다르다.
- 제출 확인창이 빈 문항 번호를 보여 주지 않는다. 리뷰가 첫 오답이 아니라 1번부터 열린다. "오답 7 + 미응답 8"과 "오답 15"가 섞여 표시된다.
- 완료 카드에 "응시 가능"과 "완료" 칩이 동시에 붙는다. "원시험" 같은 용어가 설명 없이 쓰인다.
- 홈의 PWA 설치 배너가 시작 버튼을 가린다.
- Tab 키로 1번 문항까지 84번을 눌러야 하고 문항 이동 단축키가 없다. 배점을 구간 단위로 일괄 지정할 수 없다.
- 변별도가 문항 자신을 포함한 총점으로 계산된다(비교정 점이연).

## 더 원하는 점
**학생**
- 학생용 성장 화면: 과목·개념별 누적 추이와 "계속 약한 개념"
- 마감 알림, "오늘 해야 할 시험" 요약
- 링크·QR 한 번으로 로그인(이름·반·코드 자동 입력), 로그인 후 원래 화면으로 복귀
- 폰용 "문제 크게 / 답안 크게" 모드, 저학년 모드
- 재시험 전에 해설을 읽는 단계, 시차를 둔 재출제
- 제출 후 필기 보관

**교사**
- 시험 복제·템플릿, 문항 은행
- 정답 정정 + 재채점 diff 미리보기 + 변경 이력, 성적 공개 예약
- 주관식·복수정답·부분점수·200문항·수능형 배점 프리셋
- 이름이 들어간 응답 행렬 XLSX와 구글시트 연동
- 반 단위 학부모 리포트 PDF·링크, 원클릭 미응시 독촉
- 5분 시작 가이드(샘플 시험과 샘플 명단 내장)
- PDF에서 문항 수·제목·답지 자동 감지
- 종이 OMR 사진 채점(종이 병행 이행용)

**원장**
- 강사·조교·열람자 초대와 역할 편집, 지점 범위 권한

## 우선 추천 순서
1. **바로 고칠 수 있는 것**
   - pdfjs import를 legacy 빌드로 교체
   - 폰 PDF 높이 확보
   - "선생님 모드" 숨김
   - 로그인 오류 문구 정리
   - 이력 "최근 흐름" 방향 수정
   - 모바일 "저장됨" 표시 노출
2. **학생 진입 마찰**
   - 로그인 3칸을 처음부터 표시
   - 로그인된 학생은 입장 팝업 생략
   - 세션 만료 화면에 로그인 직행 버튼
   - 대시보드 "할 일" 집계·정렬·마감 시각 정리
3. **채점 신뢰**
   - 재채점 워크플로
   - 복수정답·전원정답
   - 정답 수정 시 경고
4. **규모**
   - 100건 분석 상한을 시험 단위로 변경
   - 상한을 플랜과 연동
   - 상한 초과 시 화면 전체 실패 대신 일부 표시
5. **조직**
   - 강사 초대와 역할 관리
   - 조직 대시보드
   - 이름이 들어간 내보내기
