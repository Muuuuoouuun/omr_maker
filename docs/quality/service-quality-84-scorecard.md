## 채점 근거

### 제품 완성도 84

- 교사 시험 제작·배포·분석, 학생 응시·제출·복습·재응시가 하나의 제품 흐름으로 연결된다.
- 질문 outbox가 앱 시작, 온라인 복귀, 세션 변경, 화면 재표시에서 현재 학생 범위로 자동 복구된다.
- 데모/로컬 대체 동작과 운영 준비 진단이 구분된다.
- 운영 Supabase 적용 증거, 실결제, 실제 카카오 연동은 아직 없어 감점했다.

### 핵심 워크플로 87

- 교사→학생→교사 전체 흐름, 이탈 기록, 제출 영수증, 질문 재전송을 단위·브라우저 테스트로 검증한다.
- 재전송은 소유 학생과 signed session을 함께 확인하고 브라우저 전역 lock으로 직렬화한다.
- 이전 버전의 소유자 없는 질문은 안전상 수동 재시도가 필요하고, 실제 Supabase 연결 전체 브라우저 여정은 남아 있어 감점했다.

### UI/UX 92

- 승인된 설계 1의 균형형 위계, 핵심 CTA 강조, 역할 선택의 균형, 여백 리듬을 데스크톱·모바일에서 확인했다.
- 과업 상태, 동기화, 이탈 경고, 제출 결과의 피드백이 분명하다.
- 결과 화면 일부의 작은 캡션·밀집된 보기 전환과 일부 `transition: all` 때문에 감점했다.

### 접근성·반응형·PWA 91

- 교사 공통 헤더에 본문 바로가기와 명확한 main landmark를 추가했다.
- 키보드 파일 업로드, 모달 포커스 순환·복귀, 탭 키보드 이동, 터치 목표, overflow를 회귀 테스트한다.
- `orientation:any`, 감소된 모션, PWA 진단, 모바일 학생 제출 흐름을 검증한다.
- 실제 HTTPS 설치/홈 화면 실행 증거와 일부 36px 결과 허브 컨트롤 때문에 감점했다.

### 엔지니어링 품질 87

- 깨끗한 설치, 타입 검사, 린트, 운영 빌드와 전체 단위·계약 테스트가 통과한다.
- 실제 PostgreSQL 17에서 스키마와 모든 마이그레이션을 순서대로 적용하고 경계 assertion을 실행한다.
- 큰 화면 파일과 roster 동시 수정 충돌 방지, 원격 CI의 현재 SHA 증거가 아직 없어 감점했다.

### 보안·운영 준비도 81

- 교사 mutation은 viewer·미인증·mockup을 fail-closed로 차단하고 역할 있는 사용자만 service-role 경로에 진입한다.
- PBKDF2 반복·salt·hash 범위를 제한하고 Electron 외부 이동을 HTTP(S)로 제한했다.
- CSP와 Supabase RLS/RPC 경계를 강화하고 교차 조직·권한 상승 차단을 실제 PostgreSQL에서 확인했다.
- 운영 배포 전환, 공유형 rate limiter, 중앙 관측성, `unsafe-inline` 제거가 남아 있어 가장 낮게 채점했다.

## 판정 범위

이 점수는 저장소와 로컬 릴리스 후보의 품질 게이트 판정이다. 운영 Supabase 적용, 실제 HTTPS PWA 설치, 원격 CI의 동일 커밋 통과까지 확인하는 운영 배포 승인을 의미하지 않는다.
