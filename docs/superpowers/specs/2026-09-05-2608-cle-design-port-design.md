# `2608.cle` 디자인 요소 이식 설계

## 배경

현재 작업 브랜치는 `codex/initial-ops-100`이고 디자인 원본은 원격 `origin/2608.cle`의 `4defa9c`이다. 두 브랜치는 `4666c01` 이후 크게 갈라졌으며, 현재 브랜치에는 원격 디자인 브랜치보다 새로운 운영·보안·캐시·배포 안정화 변경이 다수 포함되어 있다. 따라서 원격 커밋이나 파일을 그대로 체리픽하지 않고, 검증된 시각 요소만 현재 구조에 맞게 다시 적용한다.

사용자가 선택한 권장 범위는 다음 두 화면이다.

1. 홈 역할 선택 화면
2. 교사 대시보드 개요 화면

## 목표

- 홈 첫 화면을 `2608.cle`의 학습 코치 콘셉트에 가깝게 만든다.
- 교사 대시보드 첫 화면을 사이드바, KPI 카드, 주요 분석 차트, 최근 시험 패널이 명확한 편집형 레이아웃으로 만든다.
- 현재 브랜치의 모든 데이터 흐름과 동작 계약을 유지한다.
- 데스크톱과 모바일에서 레이아웃, 접근성, 오버플로, 테마 동작을 검증한다.

## 비목표

- `2608.cle`의 인증, 회원가입, 반 명단 저장, 프리미엄 복구 추천 기능을 가져오지 않는다.
- Supabase 설정, 마이그레이션, 서버 액션, 서비스 계층, 요금제 판정 로직을 변경하지 않는다.
- 학생 분석·결과 보기와 시험·회원 관리 화면을 이번 범위에 포함하지 않는다.
- 현재 브랜치에 추가된 운영 상태, 읽기 전용 강등, 캐시, 알림, 초대 수명주기 기능을 제거하거나 단순화하지 않는다.

## 접근 방식

### 선택: 현재 구조 위에 수술식 디자인 이식

원격 브랜치의 완성된 화면을 참고하되 현재 컴포넌트의 props, 이벤트 핸들러, 서버/클라이언트 경계와 데이터 모델은 유지한다. JSX는 시각 계층을 만드는 데 필요한 범위에서만 재배치하고, 스타일은 원격 디자인에서 필요한 규칙만 선별해 현재 스타일 시스템에 맞춘다.

이 방식은 부분 체리픽보다 수작업이 많지만, 서로 다른 기능 세대의 코드를 섞어 생기는 회귀를 피할 수 있다. 색상과 배경만 복사하는 방식보다 레이아웃 재현도도 높다.

## 화면 설계

### 홈 역할 선택

- 중앙 브랜드 마크와 짧은 안내 문구를 첫 시선 영역에 둔다.
- 큰 청색–보라색 제목과 한 줄 설명으로 역할 선택 목적을 분명히 한다.
- 학생과 선생님 역할을 동일한 위계의 큰 카드 두 개로 보여준다.
- `omr-home-learning-coach-bg-v2.png`를 텍스트 없는 장식 배경으로 사용한다.
- 기존 학생/교사 로그인 전환, 입력, 오류 메시지, 제출, 뒤로 가기 동작은 유지한다.
- 역할 선택 상태는 원격 시안의 밝은 표현을 사용하되, 로그인 상태와 앱 전반의 기존 테마 제어는 제거하지 않는다.
- 모바일에서는 두 역할 카드의 터치 대상과 텍스트 가독성을 유지하면서 화면 너비를 넘지 않게 한다.

### 교사 대시보드

- 기존 교사 레이아웃과 내비게이션 계약을 유지하면서 개요의 첫 화면을 편집형 위계로 정돈한다.
- 상단에는 단순한 대시보드 제목과 시험 생성 주요 행동을 둔다.
- 핵심 지표 네 개를 동일한 카드 위계로 표시한다.
- 점수 추이와 참여 정보를 첫 화면의 지배적인 분석 영역으로 배치한다.
- 최근 시험은 주요 차트 옆 또는 바로 아래의 컴팩트 패널로 구성한다.
- 시험/학생 분석 탭, 검색, 세션, 알림, 동기화, 내보내기, 세부 패널 및 현재 데이터 원천은 그대로 유지한다.
- 데이터가 없거나 로딩·오류·강등 상태일 때도 기존 상태 컴포넌트와 행동 제한을 보존한다.

## 구현 경계

우선 검토 대상은 다음과 같다.

- `public/assets/omr-home-learning-coach-bg-v2.png`
- `src/app/page.tsx`
- `src/app/globals.css`
- `src/app/teacher/dashboard/page.tsx`
- `src/components/dashboard/MockupOverview.tsx`

필요하면 기존 대시보드 하위 컴포넌트에 시각적 props 또는 클래스만 추가할 수 있다. 비시각 로직 파일 변경이 필요해지는 경우에는 디자인 이식 범위를 벗어난 것으로 보고 구현을 중단해 재검토한다.

## 보존해야 하는 계약

- 로그인과 역할 선택의 현재 이벤트 및 서버 액션
- 교사 대시보드의 실제/데모 데이터 선택과 캐시 정책
- 로딩, 빈 상태, 오류, 읽기 전용 강등 상태
- 시험 생성 및 상세 화면 이동
- 알림, 검색, 로그아웃, 세션 표시
- 모바일 최소 44px 상호작용 대상과 키보드 접근성
- `prefers-reduced-motion`과 앱의 모션 비활성화 설정
- 현재 라이트/다크 테마 동작

## 오류 처리

이번 변경은 새 네트워크 요청이나 데이터 변환을 만들지 않는다. 기존 오류 경계와 상태 표현을 그대로 사용한다. 장식 배경을 불러오지 못하더라도 역할 선택 컨트롤과 텍스트는 읽고 사용할 수 있어야 하며, 배경은 기능 의존성이 없는 점진적 향상 요소로 취급한다.

## 테스트 및 QA

- 변경 전에 홈 및 대시보드의 핵심 UI 계약을 표현하는 표면 테스트를 추가하거나 기존 테스트를 보강한다.
- 홈 역할 선택, 교사 로그인 전환, 대시보드 탭/주요 행동이 기존과 동일하게 작동하는지 검증한다.
- 관련 Vitest 테스트, ESLint, TypeScript 검사를 실행한다.
- 프로덕션 빌드로 CSS와 라우트 컴파일을 검증한다.
- 데스크톱과 모바일 뷰포트에서 홈과 교사 대시보드를 각각 캡처하여 원격 시안과 비교한다.
- 수평 오버플로, 첫 화면의 주요 위계, 44px 터치 대상, 키보드 포커스, 다크 모드, 모션 감소 설정을 확인한다.

## 완료 기준

1. 홈과 교사 대시보드가 선택한 원격 콘셉트의 시각 위계를 재현한다.
2. 현재 브랜치의 기능·데이터·보안 동작이 유지된다.
3. 관련 자동 테스트, 타입 검사, 린트, 빌드가 통과한다.
4. 데스크톱과 모바일 시각 QA에서 P0, P1, P2 문제가 남지 않는다.
